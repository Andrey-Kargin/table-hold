Тестовое задание: страница бронирования столика.

Стек: React, Next.js, TypeScript, CSS Modules

## Запуск

```
npm install
npm run dev
```

## Решения

Форму и экран подтверждения разнёс по компонентам, проверки вынес в `utils/validation.ts`, чтобы не мешать всё в одном файле. Телефон чищу от скобок/дефисов и проверяю на 11 цифр с 7 или 8. Отправку замокал через `setTimeout`, как в задании.

Стилистику взял с [saveur.tech](https://saveur.tech/): шрифты Fraunces, Manrope и JetBrains Mono, кремовый фон и золотой акцент. Фавиконку тоже взял с сайта (`/favicon.svg`, буква S). Курсор смотрел там же: кольцо + золотая точка, на ховере круг чуть растёт. Свой собрал на `requestAnimationFrame`, без библиотек (Был уже подобный опыт и код в запасе). Нативный календарь даты кастомный курсор не рисует, поэтому при открытии я его прячу, а списки времени и гостей сделал своими, чтобы курсор на них оставался.
